# YYZ 组织支持服务目录

以下事项属于跨项目组织能力，不建立 YYZ 私有常驻 Agent：

| Request Type | 典型事项 | 建议组织承接方 |
| --- | --- | --- |
| `software_copyright` | 软著材料、申请、补正和归档 | 知识产权/行政支持 |
| `domain` | 域名申请、备案、续费和归属 | IT/行政/法务 |
| `platform_account` | 联盟、小程序、广告或开发者账号 | 对应业务支持与账号管理员 |
| `legal` | 合同、协议、隐私、合规和争议 | 法务 |
| `finance` | 结算、发票、核减和财务确认 | 财务 |
| `engineering` | 跨项目研发、基础设施和公共能力 | 组织研发调度 |

当前负责广告运营的员工可以兼任执行人，但商业化运营任务和组织支持任务必须使用不同任务类型。

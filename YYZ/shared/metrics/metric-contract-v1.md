# YYZ 核心指标契约 v1

本文件定义多 Agent 协作时必须使用的最低指标边界。具体报表字段映射后续在数据契约中补充。

| 指标 | 定义 |
| --- | --- |
| 收入 | 上游联盟或广告主按当前事实源确认给 YYZ 的收入 |
| 成本/媒体结算 | YYZ 按有效订单或约定规则支付给媒体的金额 |
| 毛利 | `收入 - 成本` |
| 毛利率 | `毛利 / 收入`，收入为 0 时不计算 |
| YYZ 收入 ARPU | `收入 / 同口径 DAU` |
| 媒体结算 ARPU | `成本 / 同口径 DAU` |
| YYZ 毛利 ARPU | `毛利 / 同口径 DAU` |
| 变现 ROI | `同范围收入 / 同范围成本` |
| 申请 UV 渗透率 | `申请 UV / 同口径 DAU` |
| 完成 UV 渗透率 | `完成 UV / 同口径 DAU` |
| 申请转完成率 | `完成 UV / 申请 UV` |
| 人均完成订单 | `完成订单 / 完成 UV` |
| 每 DAU 完成订单 | `完成订单 / 同口径 DAU` |

任何 ARPU、ROI、转化率都必须附时间、媒体、预算、端、去重、归因和数据截止时间。不得只写“媒体
ARPU”而不说明是媒体结算、YYZ 收入还是 YYZ 毛利。

# Q3 媒体增长思路

日期：2026-08-03

## 1. 背景与目标

当前 Q3 媒体增长讨论基于 Q2 大盘指标与现有岗位目标展开，重点不是单点运营动作，而是把媒体增长工作拆成可执行、可验证、可复盘的季度方案。

当前大盘：

- DAU：43 万
- 申请渗透率：60%
- 完成渗透率：32%
- 媒体 ARPU：1.3 毛，即 0.13 元

Q3 目标：

- 申请渗透率：70%
- 完成渗透率：40%
- AI 落地：5 个 Skill

媒体增长岗位的核心定位：

- 提升媒体 DAU。
- 提升 DAU 到申请任务 UV 的转化。
- 提升 DAU 到完成任务 UV 的转化。
- 提升媒体 ARPU 和经营质量。
- 将可复用的分析、诊断和运营动作沉淀为 AI Skill。

## 2. 目标量级拆解

按当前 43 万 DAU 不变粗算：

| 指标 | 当前 | Q3 目标 | 增量 |
| --- | ---: | ---: | ---: |
| 申请 UV | 43 万 x 60% = 25.8 万 | 43 万 x 70% = 30.1 万 | +4.3 万 |
| 完成 UV | 43 万 x 32% = 13.76 万 | 43 万 x 40% = 17.2 万 | +3.44 万 |
| 申请到完成转化率 | 32% / 60% = 53.3% | 40% / 70% = 57.1% | +3.8pp |
| 媒体日收入估算 | 43 万 x 0.13 = 5.59 万元 | 需另定目标 | 待拆 |

这组数字对应三层增长要求：

1. 申请渗透率从 60% 到 70%，意味着在 DAU 不变时，每天要多约 4.3 万申请 UV。
2. 完成渗透率从 32% 到 40%，意味着在 DAU 不变时，每天要多约 3.44 万完成 UV。
3. 申请到完成转化率需要从约 53.3% 提升到约 57.1%，不能只靠增加申请曝光，还要提升申请后的完成效率。

因此，Q3 不能只做入口曝光或媒体维护，需要同时推进：

- DAU 增长。
- 申请渗透率提升。
- 完成渗透率提升。
- 完成深度与媒体 ARPU 提升。
- 运营方法和分析能力 Skill 化。

## 3. Q3 工作拆解框架

### 3.1 DAU 增长

媒体增长不能只吃现有 43 万 DAU，需要持续寻找新增流量和存量恢复机会。

重点问题：

- 哪些媒体有新增 DAU 空间？
- 哪些存量媒体存在 DAU 下滑或入口覆盖不足？
- 哪些 CID、端、版本、入口存在流量损耗？
- 哪些媒体合作卡点需要商务、产品、技术协同解决？
- 哪些媒体可以通过新入口、新版本或新活动恢复增长？

建议建立媒体 DAU 机会表：

| 媒体 | 当前 DAU | Q3 目标 DAU | 增量来源 | 关键动作 | 风险 |
| --- | ---: | ---: | --- | --- | --- |
| 媒体 A | | | 入口升级 / 版本覆盖 / 新 CID | | |

### 3.2 申请渗透率提升：60% -> 70%

申请渗透率衡量 DAU 中有多少用户产生任务申请行为。提升申请渗透率的核心是让更多用户愿意从媒体入口进入任务链路，并点击具体任务。

可拆动作：

- 入口位置优化：任务中心、福利页、签到链路、消息触达、弹层、首页资源位等。
- 入口文案优化：突出奖励感、确定性、低门槛和任务收益。
- 任务列表优化：首屏排序、任务标题、奖励展示、任务难度、任务类型组合。
- 媒体分层运营：优先抓高 DAU、低申请渗透率媒体。
- 用户分层运营：新用户、低活跃用户、高完成用户使用不同任务和文案策略。

每周建议输出：

- Top 10 媒体申请渗透率排行。
- Bottom 10 高 DAU 低申请媒体清单。
- 2 个入口、文案或排序实验。
- 每个实验的预期提升、实验范围、验证周期和止损条件。

### 3.3 完成渗透率提升：32% -> 40%

完成渗透率比申请渗透率更能体现运营深度，因为它同时受到任务理解、跳转链路、上游体验、回调成功率和奖励感知影响。

可拆动作：

- 优化任务说明，减少用户不知道怎么完成的问题。
- 排查跳转链路，包括打开慢、跳转失败、丢参、页面兼容和版本问题。
- 识别高申请低完成任务，必要时降权、下线或调整说明。
- 识别高完成高 ARPU 任务，优先提权并扩大曝光。
- 排查完成回调延迟、失败、漏数和补单问题。
- 优化奖励感知，确保用户明确知道完成后能获得什么。

建议建立“申请高、完成低”专项清单：

| 任务/预算 | 申请 UV | 完成 UV | 申请转完成率 | 问题假设 | 动作 |
| --- | ---: | ---: | ---: | --- | --- |
| 任务 A | | | | 说明不清 / 跳转慢 / 回调异常 | |

### 3.4 媒体 ARPU 提升

申请和完成做起来后，还要看每个 DAU 贡献的收入是否同步提升。

媒体 ARPU 可拆成：

```text
媒体 ARPU = 申请渗透率 x 申请转完成率 x 完成用户人均订单 x 单订单收入
```

经营视角可进一步拆成：

```text
媒体收入 = DAU x 媒体 ARPU
毛利 = 收入 - 媒体结算成本
```

重点动作：

- 提升高收入任务在合适媒体和用户分层中的曝光。
- 优化高收入低完成任务的说明和链路。
- 控制低收入高占比任务，避免占用首屏和用户注意力。
- 按媒体 x 预算评估适配度，提升预算组合效率。
- 关注媒体结算单价、用户奖励和毛利率，避免单纯冲 UV 牺牲经营质量。

## 4. 媒体增长的核心分析维度

Q3 日常看盘建议至少按以下维度拆解：

| 维度 | 需要回答的问题 |
| --- | --- |
| 媒体 | 哪些媒体贡献 DAU、申请 UV、完成 UV 和收入？哪些媒体异常？ |
| CID / 入口 | 哪些入口效率高？哪些入口有曝光但无申请？ |
| 端与版本 | iOS、安卓、极速版、不同 SDK/H5 版本是否存在差异？ |
| 任务 / 预算 | 哪些任务高申请低完成？哪些任务高完成高收入？ |
| 用户分层 | 新老用户、高活跃、低活跃用户的申请和完成差异是什么？ |
| 时间 | 小时、工作日、周末、节假日前后的波动是否不同？ |
| 经营指标 | ARPU、收入、成本、毛利、毛利率是否同步改善？ |

## 5. Q3 重点机制

### 5.1 每周机会池

媒体增长不应只被动解释数据波动，而要主动提出机会。

机会池建议字段：

| 机会点 | 所属媒体 | 所属预算/任务 | 影响指标 | 预估收益 | 实验方案 | 所需支持 |
| --- | --- | --- | --- | ---: | --- | --- |
| | | | 申请 / 完成 / ARPU / DAU | | | |

每周至少沉淀：

- 2 个申请渗透率机会。
- 2 个完成渗透率机会。
- 1 个 ARPU 或毛利机会。
- 1 个媒体 DAU 增量或恢复机会。

### 5.2 实验机制

所有增长动作尽量实验化，避免做完后无法判断效果。

每个实验至少定义：

- 假设：为什么这个动作能提升指标？
- 范围：影响哪些媒体、入口、任务、用户或版本？
- 指标：看申请渗透率、完成渗透率、ARPU、毛利还是留存？
- 周期：多久看初步效果，多久决定放量？
- 止损：哪些指标恶化时回滚？
- 复盘：结果是否符合预期，下一步是什么？

### 5.3 周度复盘

周度复盘建议固定为 5 个问题：

1. 本周 DAU、申请渗透率、完成渗透率、ARPU、毛利分别怎么变？
2. 变化主要由哪些媒体、入口、任务或预算贡献？
3. 哪些实验有效，可以放量？
4. 哪些动作无效，需要回滚或改方案？
5. 下周最值得抓的 3 个机会是什么？

## 6. AI Skill 落地方案

“AI 落地 5 个 Skill”建议定义为真实业务能力沉淀，而不是简单写 5 个 Prompt。

每个 Skill 必须具备：

- 明确业务场景。
- 固定输入数据。
- 稳定输出格式。
- 真实使用频率。
- 可验证的准确率或节省时间效果。
- 错误样本和修正记录。

推荐优先落地 5 类 Skill：

| Skill | 解决的问题 | 典型输出 |
| --- | --- | --- |
| 媒体异常诊断 Skill | 每日识别 DAU、申请、完成、ARPU 异常媒体 | 异常媒体、影响金额、可能原因、建议动作 |
| 任务漏斗诊断 Skill | 找出高申请低完成、高完成低收入任务 | 任务分层、降权/提权建议、需排查链路 |
| 媒体 x 预算组合优化 Skill | 判断哪个媒体适合跑哪个预算 | 预算分配建议、放量/收缩清单 |
| 实验复盘 Skill | 自动整理实验前后变化 | 实验结论、是否放量、是否回滚 |
| 周度增长复盘 Skill | 汇总一周 DAU、渗透、ARPU、毛利变化 | 周报、下周重点、风险列表 |

验收建议：

- 每个 Skill 至少被真实业务使用 3 次。
- 输出能追溯到数据来源，不猜数、不补数。
- 结论有人工抽检记录。
- 能节省人工分析时间或发现人工容易漏掉的问题。
- 能转化为稳定 SOP 或固定看盘流程。

## 8. 最低周交付要求

Q3 每周建议固定交付：

- 媒体大盘周报：DAU、申请渗透率、完成渗透率、ARPU、毛利变化。
- Top 机会清单：高 DAU 低申请、高申请低完成、高完成低 ARPU。
- 实验记录：至少 2 个小实验，覆盖入口、排序、文案、任务组合、奖励感知或预算匹配。
- 实验复盘：判断是否有效、是否放量、是否回滚。
- Skill 进展：本周沉淀了哪个固定分析、诊断或运营动作。

## 9. Q3 关键判断标准

Q3 媒体增长是否有效，不能只看申请 UV 是否增长，还要同时看：

- DAU 是否增长或恢复。
- 申请渗透率是否提升。
- 完成渗透率是否提升。
- 申请到完成转化率是否改善。
- 媒体 ARPU 是否提升。
- 收入、毛利和毛利率是否健康。
- 是否形成可复用的实验、复盘和 Skill 能力。

最终目标不是单纯把两个渗透率数字做上去，而是建立一套可持续的媒体增长方法：能看盘、能拆指标、能找机会、能做实验、能复盘、能沉淀。

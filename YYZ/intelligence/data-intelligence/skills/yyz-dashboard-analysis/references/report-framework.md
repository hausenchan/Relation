# YYZ Report Framework

## Part1: 营收角度

1. 项目总成本、毛利、组成和波动原因。
2. 预算：总成本、毛利、分预算、组成和波动原因。
3. 预算：预算分媒体角度，同一预算跑不同媒体的组成和波动原因。
4. 流量：总成本、毛利、分媒体、组成和波动原因。
5. 流量：媒体分预算角度，同一媒体跑不同预算的组成和波动原因。

## Part2: 漏斗角度

1. 预算：总角度、预算做任务总漏斗、分预算漏斗、人均订单/完成人均完成。
2. 流量：总角度、流量汇总做任务漏斗、分媒体漏斗、人均订单/访问人均完成。

## Part3: 汇总

- 汇总关键波动。
- 解释原因：从收入、成本、预算、媒体、漏斗拆解。
- 给出可执行优化建议：放量、降本、止损、监控阈值、数据口径补齐。

## Required Comparisons

- Target day vs compare day.
- Target day vs Apr-Jun historical daily average.
- Where available, target dimension rows vs compare dimension rows by matching budget/media names.

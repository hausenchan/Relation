Android 商务移动端 UI 设计稿

定位为商务人员移动工作端。底部 5 个 Tab：任务、商机、人脉、公司、其他。前四个承接高频业务动作，其他承载目标、周报、策略、需求、文档中心。

风格紧凑、清爽、偏执行工具，不做 Web 菜单缩小版。
交互列表卡片 + 状态标签 + 底部主操作，筛选用底部弹层。
重点让商务人员快速处理任务、推进商机、查人脉、看公司。
